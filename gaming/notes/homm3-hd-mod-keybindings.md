# Keyboard shortcuts in HOMM3 HD Mod

## Adventure Screen

- T = town, repeated pressing scrolls through towns
- H = hero, repeated pressing scrolls through heroes
- E = End turn
- ESC = exit game
- G = thieves guild
- V = view world
- K = kingdom overview
- B = marketplace
- N = New Game
- Right Click (Hold) + move mouse = drag map
- Mouse wheel (Hold) + move mouse = drag map
- F5 = Toolbar

## Adventure Map (only when Hero is selected)

- Enter = enter hero screen
- Space = revisit object
- M = move hero
- Arrow keys = move hero one hex in that direction (can't go diagonal)
- Number pad arrow keys = move hero one hex in that direction (CAN go diagonal with 1, 3, 7, 9)
- C = cast spell
- D = dig
- R = shows a square around the hero for dimension door limits
- Right Click (Hold) + move mouse = drag map
- ALT (Hold) + move mouse = See movement points required to reach tile
- SHIFT + Left Click hero sprite = Make clicked hero the active one

## Recruit troops screen

- M = maximum
- Enter = Buy

## Creature Screen

- U = upgrade (when available, enter to confirm)
- ALT + left click D = dismiss unit

## Combat screen

- Alt = alternate attack (ranged use melee attack, activate juggernaut laser beam, etc.)
- W = Wait
- D = Defend
- G = Area attack (with gogs and liches)
- C = cast spell
- I = Show hero stats permanently
- CTRL + mouse-over creature = See general movement
- SHIFT + mouse-over creature = See exact movement (calculate obstacles)
- Q = Finish combat with Quick Combat
- Enter = accept
- Esc = cancel

## While in Town (Castle screen)

- Space = Move hero from garrison into castle, and vice versa
- F10 = Switch ARMIES from garrison into castle, and vice versa
- B = Open marketplace
- \*All shortcuts for “Hero screen” also work

## Hero screen (also works in Garrisons, Castles, and Hero Trades)

- CTRL + Click creature = Make 1 stacks
- SHIFT + Click creature = Evenly separate stack
- CTRL + Shift + left click = fill all empty slots with 1-stacks
- ALT + Click creature = Merge all stacks of clicked creature into 1 big stack
- SHIFT + ALT + Click creature = Dismiss creature (ENTER to accept, ESC to cancel)
- CTRL + Click creature portrait in castle screen to instantly buy the clicked creatures
- SHIFT + Click (on equipped artifact) = move to backpack
- ALT + Click (on equipped artifact or slot) = choose from backpack

## Hero trade screen

- CTRL + Click = move artifact to other hero
- \*All shortcuts for “Hero screen” also work

## System

- CTRL + NUM+/NUM- = Switch filter setting
- SHIFT + NUM+/NUM- = Switch second filter setting
